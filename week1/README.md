## 📌 Overview

This repository contains the work completed during **Week 1** of the **Data Visualization Trainee – Early Remote Internship** at **Excelerate**.

The primary objective of Week 1 was to understand the Opportunity dataset, assess its quality, clean and prepare the data, and document every step to establish a reliable foundation for future analysis and visualization.

---

## 🎯 Objectives

- Understand the structure of the Opportunity dataset
- Explore and document dataset variables
- Create a comprehensive Data Dictionary
- Identify data quality issues
- Clean and standardize the dataset
- Document all cleaning decisions
- Prepare an analysis-ready dataset for Week 2
